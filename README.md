
# Uganda Coffee Price & Risk Platform

A commodity risk analytics platform for Uganda's coffee export market.

**Live demo:** https://uganda-coffee-platform.streamlit.app

## What it does
- Historical Arabica and Robusta price analysis (2000–2026)
- UGX/USD exchange rate impact analysis using Bank of Uganda data
- 12-month price forecast with confidence intervals
- Interactive revenue simulator with scenario stress testing
- ERA5 satellite weather and crop health monitoring
- Signal-based market recommendation engine

## Data sources
- ICO / World Bank — global coffee prices
- Bank of Uganda — UGX/USD exchange rates
- Copernicus ERA5 — satellite climate data

## Tech stack
Python · Pandas · Prophet · Scikit-learn · Plotly · Streamlit · XArray
